# rbw-intake-assets

Static code for the Rainforest Bodyworks new-client intake form (v1.1.0). Code only: no client data, no secrets.
Served via jsDelivr at https://cdn.jsdelivr.net/gh/seakmedia/rbw-intake-assets@v1.1.0/form/ and loaded with Subresource Integrity hashes (see form/SRI.json).
Source of truth: the private rainforest-bodyworks repo, studio-code/intake/.
